# キムワイプ卓球サイト 更新方法

このサイトは **HTML・CSS・JavaScript** だけで動きます。PHPは不要です。
GitHub Pagesへは、このフォルダの中身をそのままアップロードできます。

## 日時・料金・参加方法・文章を変える

`index.html` をテキストエディタで開き、該当する文字を変更します。

## 色を変える

`css/style.css` の先頭にある `:root` 内を変更します。

| 変数 | 変更する色 |
| --- | --- |
| `--color-blue` | 主な差し色 |
| `--color-bg` | 背景色 |

## ロゴを変える

`images/logo.png` を同じ名前の画像で上書きします。
縦横比の違う画像でも収まる設定です。

## ヒーロー写真・背景写真を変える

以下のファイルを同じ名前の画像で上書きします。

| ファイル | 表示場所 |
| --- | --- |
| `images/hero.jpg` | 最初に大きく表示される写真 |
| `images/background.jpg` | ヒーロー右側の薄い背景 |

## その他の写真を変える

| ファイル | 表示場所 |
| --- | --- |
| `images/about.jpg` | 「キムワイプ卓球とは」の写真 |
| `images/craft.jpg` | ペーパークラフトの写真 |

## 昨年の写真を追加する

1. `images/gallery/` に JPG・PNG・WebP 画像を入れます。
2. `js/gallery-images.js` を開き、ファイル内の説明に従ってファイル名と説明を追加します。
3. 表示順は、ページを開くたびに自動でランダムになります。

> **注意：** このサイトでは、JavaScriptだけでフォルダ内の画像を自動検索することはできません。写真を追加したときは、`js/gallery-images.js` の一覧も更新してください。

## Font Awesomeについて

アイコンはCDNから読み込むため、表示にはインターネット接続が必要です。
アカウント登録や追加設定は不要です。
